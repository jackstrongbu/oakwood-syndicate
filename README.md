# Oakwood Syndicate

Weekly £1 football picks: league table and picks grid. `index.html` is the main page, regenerated by Claude after each week's results.

## Live scores (public site only)
`extras.js` + `netlify/functions/scores.mjs`: matches each pick in the latest week to a live fixture and refreshes every minute while games are on. Free source is ESPN's scoreboard feed (Premier League to League Two, Scottish Prem and Championship, cups); not National League or Scottish League One/Two. If the server can't reach the feed, the page fetches it from the viewer's browser, and the panel hides itself if neither works.

## Rebuilding index.html
Keep `<script src="extras.js" defer></script>` just before `</body>` and keep the data in a top-level `const DATA=...`, so live scores still load.
